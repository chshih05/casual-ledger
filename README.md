# 隨便記

個人記帳網頁：以支出為主，也可以記收入。帳本存在瀏覽器內建的資料庫裡，可以用 Google 帳號在手機和電腦之間同步。

**網址：** <https://chshih05.github.io/casual-ledger/>

## 使用方法

### 加到手機主畫面
- **Android：** 用 Chrome 開啟網址 → 右上角選單 →「加到主畫面」（或「安裝應用程式」）。
- **iPhone：** 用 Safari 開啟 → 分享 →「加入主畫面」。
- 加到主畫面後，沒有網路也能開啟和記帳。
- **捷徑（Android）：** 長按主畫面上的「隨便記」，選「記一筆支出」或「記一筆收入」直接打開記帳頁。已經加到主畫面的，要等 Chrome 自己更新主畫面圖示後才會出現（可能要一天；急的話先下載備份，再刪掉重新加入）。iPhone 沒有這個功能。

### 記一筆
1. 點下方「＋記一筆」，需要時切換「支出／收入／退款」（退款見下方）。
2. 選分類，輸入金額（可以打算式，例如 85＋35、55×3；先乘後加減，上方即時顯示算好的金額，點一下就把算式換成金額）。沒有合適的分類時，點分類最後一格「＋ 新增」，新增後會直接選取。
3. 店家或收入來源可留白：下方推薦最近 6 個月在這個分類常用的 8 個，打字可以搜尋全部。輸入的店家以前記過時，會出現「看「店家」以前的 N 筆紀錄」，點開只能看，不會打斷正在記的這一筆。輸入沒記過、但和以前相似的名稱時（例如「全家便利商店」和「全家」、「路易沙」和「路易莎」），會提示改用以前的名稱，點一下就換過去，同一家店才不會分開算。
4. 視需要填備註；日期點「今天」或「昨天」，其他日期點「其他日期」開日曆。按畫面最下方的「儲存紀錄」。

點首頁的紀錄可以修改或刪除；刪除後 10 秒內可以按「復原」。

**退款與朋友還錢：** 退貨退款、朋友還你代墊的錢，在記帳頁上方選「退款」，選原本的分類（和店家），填退回的金額。這筆會從那個分類（和店家）的支出扣掉，不算收入：例如聚餐先幫大家付 1,200、朋友還你 900，晚餐就只算你自己的 300。首頁用綠色的「-$900」和「退款」標示，每天的合計另外列出退款；本月支出總額、預算、統計、店家紀錄都是扣掉退款後的金額。搜尋「退款」可以找出所有退款。以前記成收入的退款，可以點開後改選「退款」和原本的分類。

**返回手勢：** 記帳頁、明細、分類編輯、對話框和設定分頁，都可以用手機的返回手勢（或瀏覽器的上一頁）關掉，回到上一個畫面，不會離開網頁。記帳頁沒按儲存就返回，內容直接捨棄。

### 查看與統計
- **首頁：** 本月支出總額與依日期分組的紀錄，每天標出當天的支出合計（有收入時另外列出），上方箭頭切換月份，點中間的月份直接回到這個月（統計頁整年時回到今年）。停在這個月時，紀錄會往前補上個月最後幾天，補到和這個月一樣多天（例如 11/2 列出 10/4～11/2），月初也看得到前幾天記了什麼；補上的紀錄在「10 月・不計入本月合計」分隔線下方，不算進本月支出總額，也不算進清單上方的筆數（例如「本月 96 筆」；搜尋時是「共 N 筆」，算找到的筆數）。可以搜尋店家、備註或分類，一律找全部月份；按「篩選」可以只看某個分類，或金額至少多少，也可以和關鍵字一起用（儲存紀錄後會清掉）。搜尋時會顯示找到幾筆與合計（支出、收入分開算），例如查「星巴克」總共花了多少；只看某個月的合計，到統計頁點店家。有設定預算時，總額下方會顯示預算還剩多少。
- **統計：** 選「按月／整年」與「支出／收入」，看分類占比和店家排行，點項目看明細。金額很小、四捨五入是 0% 的寫「不到 1%」。店家排行先列金額最高的 10 個，按「顯示全部」看其他的。整年時另外列出 1～12 月的金額，點月份會跳到該月。
- **店家（分類）的所有紀錄：** 明細上方可以切換「這段期間／全部時間」。全部時間依月份列出筆數與小計，並顯示平均每筆（只算買東西的那幾筆，不含退款）、最近一次和第一次。只算同一種類型：店家看支出（已扣退款）、收入來源看收入。
- **和上月（去年）比較：** 總額下方顯示比上月多或少多少、日均（整年時是月均）。這個月還沒過完時，只和上個月的同一段日子比（例如都只算 1～15 日）。下方列出各分類的差額，變化大的排前面。
- **每日支出：** 按月、支出時有這個月每天的長條圖，今天用主題顏色，上方標出花最多的那一天；點長條列出那天的紀錄。
- **近 12 個月：** 按月時有近 12 個月的長條圖，目前的月份用主題顏色；點長條切換到那個月。上方可以選只看一個分類（例如「飲料」每個月花多少）。

### 預算
- 設定 →「預算」：設定每月總預算，也可以替個別支出分類設上限；留白或 0 就是不設定。
- 首頁顯示總預算還剩多少、這個月還有幾天、平均每天還能花多少；長條上的白線是「今天」在這個月的位置。分類預算只在快用完（用到八成）或超出時出現在首頁，全部的在統計頁「按月、支出」。
- 記一筆後如果讓預算第一次用到八成或超出，會跳出提醒。

### 固定收支
- 設定 →「固定收支」→「新增」：房租、訂閱、薪水這類每月（或每年）固定的收支，到了那天會自動記一筆，首頁標示「固定」。
- 第一次的日期如果在今天以前，儲存後會先補記到今天為止的（最多 120 筆）。31 日遇到小月記在月底；2/29 遇到平年記在 2/28。
- 自動記下的紀錄可以照常修改或刪除；刪掉的那一天不會再補回來。修改規則只影響之後的紀錄。
- 「暫停」期間不會記帳，按「繼續」後從下一次開始，不補記暫停期間。刪除規則時，已經記下的紀錄會保留。
- 清單上方列出合計，例如「固定支出每月 NT$ 889，一年約 NT$ 10,668」；每年一次的（例如年繳保險）另外列出、算進一年的合計。暫停中、已結束的不算。

### 設定頁
- **第一頁：** 上方是雲端同步狀態與「下載完整備份」，下方是各分頁。分頁可以用手機的返回手勢回到第一頁。
- **記帳與首頁：** 首頁只顯示支出，或一併顯示收入與結餘；可開啟「儲存並再記一筆」；主題顏色可以選霧藍（預設）、天青、灰白或紫（只套用在這台裝置，不會同步）。
- **分類：** 點分類可以改名、換圖示或刪除（沒有紀錄與固定收支使用的才能刪除）；按住左邊的把手拖曳調整順序（用鍵盤時在把手上按上下鍵）。預設分類都是兩個字（飲料、帳單、醫療、娛樂、其他、獎金…），記帳頁一格放得下；以前的帳本裡還是原本四個字（例如「飲料點心」）的，更新後第一次開啟時會自動改成短的，自己改過的名稱不動。
- **合併分類：** 點分類 →「合併到…」，選要併到哪個分類：這個分類的紀錄和固定收支都搬過去，然後刪除這個分類（它的預算一起刪除，選的分類預算不變）。合併後分不開，所以合併前的帳本會保留一份，可以在「資料與備份」按「還原合併前帳本」。
- **新增分類：** 按「＋ 新增支出分類」（或記帳頁分類最後一格「＋ 新增」）。名稱和圖示都由你決定：先打名稱，會依名稱自動選一個相近的圖示（例如打「加油」就選加油的圖示、打「宵夜」就選串燒），也可以直接在下面挑；先挑圖示時，名稱會帶入圖示的名稱。上方預覽在記帳頁的樣子。自己挑過圖示後，改名稱就不會再換圖示。
- **店家與收入來源：** 分兩頁，只列最近 6 個月最常用的 12 個，其他的用搜尋或「顯示全部」找。每個名稱一行，點一下打開以前的所有紀錄；紀錄上方可以改名、合併重複的名稱，或停用（不再推薦，歷史紀錄保留）。

### 備份、匯出與換手機
- 設定 →「資料與備份」→「下載完整備份」，會下載一個 `.json` 檔（包含預算與固定收支）。
- 在新裝置按「匯入備份」：預設是合併（不刪除現有紀錄，重複的略過），也可以勾選改為完全取代。匯入前的帳本會保留一份，可以按「還原匯入前帳本」。
- **備份提醒：** 超過 30 天沒有備份、之後又新增或修改了 30 筆以上（從沒備份過就是記滿 30 筆）時，首頁會出現「記得備份帳本」。按「下載備份」後消失；按「稍後提醒」7 天內不再出現。
- **雲端自動備份：** 有連結 Google 雲端同步時，每週會在雲端另存一份完整備份（同一週只存一份，兩台裝置也不會重複存）。這份備份和同步的資料分開，只能新增、不能修改或刪除，所以誤刪或同步出錯也不會影響它。設定 →「資料與備份」→「查看雲端備份」列出最近 8 份，可以「還原」（和匯入備份一樣先列出會怎麼合併，預設不刪除現有紀錄）或「下載」成檔案。
- **匯出 CSV：** 同一頁選範圍（全部、首頁目前的月份，或某一年）後匯出，可以用 Excel、Google 試算表或 Numbers 開啟。CSV 只用來查看，不能匯入回來。退款的類型是「退款」、金額是負數，和支出加起來就是扣掉退款後的花費。

### 刪除紀錄與全部重置
設定 →「資料與備份」最下面的「刪除資料」：
- **刪除所有紀錄：** 只刪除收支紀錄；分類、店家與收入來源、預算、固定收支和設定都保留（固定收支之後到期仍會自動記帳）。
- **全部重置：** 帳本回到第一次使用時的樣子：刪除所有紀錄、店家與收入來源和固定收支，分類、預算、首頁與記帳偏好恢復預設。
- 確認視窗預設會先下載一份完整備份。刪除前的帳本也會在這台裝置保留一份，可以按「還原刪除前帳本」（重置是「還原重置前帳本」）找回。這一份和匯入、合併分類共用、只留最近一次：之後再匯入、合併、刪除或重置，就會換成那次之前的帳本。
- 有連結雲端同步時，其他裝置也會一起刪除（重置），不用再按「確認刪除並同步」；雲端每週的自動備份不受影響，也可以從那裡還原。

### 第一次使用雲端自動備份：更新 Firebase 安全規則
雲端自動備份存在新的位置，要先更新安全規則才能存（更新前，設定頁會顯示「雲端拒絕儲存備份」，同步不受影響）：
1. 打開 [Firebase 主控台](https://console.firebase.google.com/) → 專案 → Firestore Database →「規則」。
2. 先把目前規則裡你的 Gmail 記下來，再把 `firestore.rules` 的全部內容貼上，`your_gmail@gmail.com` 換回你的 Gmail（全部小寫），按「發布」。
3. 回到網頁：設定 →「資料與備份」→ 按「查看雲端備份」，會馬上補存這一週的備份（不按也會在一天內自動再試）。

### Google 雲端同步
- 設定 →「雲端同步」→「使用 Google 登入並同步」。只有白名單裡的 Gmail 能同步（目前只有擁有者本人）。
- 如果這台裝置已經有紀錄，連結前會先詢問，並建議先下載備份。
- 離線時記的帳會標示「待同步」，恢復連線後自動上傳。
- 兩台裝置改了同一筆：保留較晚修改的版本，另一個版本放在「衝突紀錄」，可以改用。
- 一次刪除很多筆時會先暫停，按「確認刪除並同步」才會刪除雲端的資料（「刪除所有紀錄」「全部重置」已經確認過，不會再暫停）。

### 版本更新
- 每次開啟網頁或從其他 App 切回來，都會自動檢查新版本。剛開啟還沒操作時直接換成新版；正在記帳時不打斷，改在頂部顯示「有新版本・點此更新」。
- 設定 →「關於此網頁」可以看網頁版本，或手動「檢查新版本」。

## 目前的問題與限制

- **帳本存在這個瀏覽器：** 帳本存在瀏覽器內建的資料庫（IndexedDB）。清除瀏覽器資料，或在 iPhone 刪除主畫面上的「隨便記」，都會刪除這台裝置上的帳本。沒有開同步時，請定期「下載完整備份」。
- **改存資料庫後第一次開啟：** 會自動把原本存在 localStorage 的帳本搬進資料庫，讀回來比對無誤才換掉舊的。這時如果還有開著的舊版分頁，它會顯示「原有資料無法讀取，已停止覆寫」並停止寫入，關掉或重新整理就好，帳本沒有遺失。
- **瀏覽器不能用資料庫時：** 例如部分無痕模式，會自動改用原本的方式存（整本帳存在 localStorage，容量大約 2 萬筆）。
- **同步不是備份：** 任何一台裝置刪除的紀錄，其他裝置也會刪除。有連結雲端時每週自動在雲端備份一次（要先更新安全規則，見上方）；沒有連結雲端時只有首頁提醒，請自己下載備份。
- **雲端備份一週一份：** 這週存了之後才記的帳，要到下週的備份才有；需要時請另外「下載完整備份」。雲端備份不會自動刪除，每份大約幾十 KB 到 1 MB，免費額度（1 GB）可以存很多年。
- **同步只開放白名單：** 目前只有擁有者本人的 Gmail 能同步。其他人也能用這個網址記帳，但帳本只存在他們自己的瀏覽器；登入同步會顯示「雲端拒絕存取」。
- **同步判斷新舊靠各裝置的時鐘：** 手機和電腦的時間差很多時，可能選錯版本（被取代的版本仍會留在「衝突紀錄」）。
- **固定收支只在開啟網頁時記帳：** 到期那天沒有開啟的話，下次開啟（或從其他 App 切回來）時補記。有連結雲端時，會先等同步完成再記，避免用到其他裝置已經改掉的規則。
- **預算以月為單位、只算支出：** 沒有年度預算，沒用完的金額也不會留到下個月。
- **店家的紀錄只認完全相同的名稱：** 「全家」和「全家便利商店」會分開算，可以在設定頁點名稱後按「合併」，把重複的名稱合在一起。
- **還沒更新的裝置：** 舊版網頁看不到預算、固定收支與退款，同步分頁可能顯示「雲端資料格式不符，已略過」；在舊版改了有預算的分類，會把那個分類的預算清掉。更新後第一次同步會從頭讀一次雲端，自動補回略過的資料（多用一次讀取額度）。
- **主畫面的名稱與圖示：** 改版後由 Chrome 自己更新，可能會先詢問；iPhone 要刪掉重新加入（刪除前先下載備份）。圖示固定是霧藍色，不會跟著主題顏色改變。
- **直接開啟 `docs/index.html` 檔案時：** 可以記帳，但不能同步，也不會離線快取或自動更新。
- **從捷徑打開記帳頁時：** 按返回手勢可能會直接回到手機桌面（Chrome 會略過還沒點過的畫面），要回首頁請按左上角「返回」。

### 資料量與速度
資料庫裡每筆紀錄各自一列，儲存時只寫入變更的那幾列；但每次儲存仍會檢查整本帳哪裡改了，所以筆數越多還是會慢一些。實測（電腦 CPU 降速 4 倍，模擬中階手機；括號內是改存資料庫之前，用同樣方法量的）：

| 筆數 | 開啟 | 儲存一筆 |
| ---: | ---: | ---: |
| 6,000 | 約 0.9 秒（0.9 秒） | 約 0.4 秒（0.5 秒） |
| 1 萬 | 約 1 秒（1.1 秒） | 約 0.4 秒（0.6 秒） |
| 2 萬 | 約 1.4 秒（1.4 秒） | 約 0.6 秒（1.1 秒） |

切換頁面只重畫看得到的那一頁，約 0.2～0.4 秒（同樣降速 4 倍、每月約 150 筆），幾乎不受總筆數影響。容量不再受 localStorage 約 5MB 的限制，資料庫可以用的空間大得多；程式設定的上限是 10 萬筆。同步狀態仍存在 localStorage，2 萬筆時約 1.5MB。

## 修改與發布（給維護者）

- 原始碼在 `src/`；`docs/` 是建置出來的網站（GitHub Pages 發布這個資料夾），**不要直接修改**。
- 修改後執行 `python tools/build.py`（只需要 Python 3，不需要 Node.js）。
- 程式排版（選用，需要 Node.js）：`npx prettier@3.3.3 --print-width 120 --single-quote --arrow-parens avoid --trailing-comma es5 --write src/js/60-app.js`（`62-budget.js`、`64-stats-compare.js`、`66-recurring.js` 也用同樣的設定）。
